# Web boda Núria & Luis

Plantilla estática preparada para GitHub Pages.

## Probarla
Abre `index.html` en el navegador.

## Publicarla en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube todos los archivos de esta carpeta a la raíz.
3. Ve a **Settings → Pages**.
4. En **Build and deployment** elige **Deploy from a branch**.
5. Selecciona `main` y `/root`.
6. Guarda.

## Privacidad
La web incluye:
`<meta name="robots" content="noindex,nofollow">`

Eso pide a buscadores que no la indexen, pero no añade contraseña.

## Tipografías
Por defecto: Playfair Display + DM Sans.

En `styles.css` están preparadas también:
- Cormorant Garamond + Montserrat
- Lora + DM Sans

## Personalizar
- Cambia textos en `index.html`.
- Pon tus fotos en `assets/images/`.
- Cambia el enlace RSVP `href="#"` por el Google Form o Tally.
- Sustituye el botón "Cómo llegar" por vuestro enlace de Google Maps.
